# 地学基礎マスター

高校3年生向けの、地学基礎を10問ずつ進める学習ゲームです。  
スマートフォンの縦画面で遊ぶことを前提にしています。

## Ver.1.4.4

モード別の表示・背景・ステージマップ演出・モード制覇演出を追加しました。

- 冒険者モード：青緑・空色／現在地 `🚪`／未解放 `🧱`
- 師範モード：生成り・茶・朱色／現在地 `⛩️`／未解放 `🔒`
- 神モード：紺・紫・星空／現在地 `🚀`／未解放 `🌑`
- ホーム画面とステージマップの両方にモード切替ボタンを配置
- 問題画面に小さなモード表示を追加
- 各モード15ステージ制覇時に専用演出を表示

## ファイル構成

```text
index.html
version.json
questions_A.js
questions_M.js
questions_G.js
modes.js
effects.js
logo.png
README.md
```

### 主な役割

- `index.html`：ゲーム本体、画面遷移、進行、セーブ、モード表示
- `modes.js`：モード別の名称、アイコン、色、制覇文言
- `effects.js`：モード制覇アニメーション
- `questions_A.js`：冒険者モード150問
- `questions_M.js`：師範モード150問
- `questions_G.js`：神モード150問
- `version.json`：公開版の最新版情報
- `logo.png`：ホーム画面のタイトルロゴ

## 更新時の確認

`index.html`内の`RELEASE_INFO`と`version.json`の次の3項目を一致させます。

- `version`
- `date`
- `message`
