# 地学基礎マスター

高校3年生向けの、地学基礎を10問ずつ進める学習ゲームです。  
スマートフォンの縦画面で遊ぶことを前提にしています。

---

## ファイル構成

```text
index.html
version.json
questions_A.js
questions_M.js
logo.png
README.md
```

### `index.html`

ゲーム本体です。

- 画面表示
- ステージ進行
- 回答判定
- セーブデータ
- バージョン表示
- 各問題ファイルの読み込み

などを管理します。

### `version.json`

GitHub上で公開されている最新版の情報を管理します。

```json
{
  "version": "1.4.2",
  "date": "2026-08-04",
  "message": "師範モード（Mパック）150問を追加"
}
```

### `questions_A.js`

Aパックの問題データです。

- 内部名称：Aパック
- 英語名：Adventurer
- プレイヤー向け表示：冒険者モード
- 150問
- 5フィールド × 3ステージ × 10問

### `questions_M.js`

Mパックの問題データです。

- 内部名称：Mパック
- 英語名：Master
- プレイヤー向け表示：師範モード
- 150問
- 5フィールド × 3ステージ × 10問

### `logo.png`

ホーム画面に表示するタイトルロゴ画像です。

### `README.md`

このファイルです。  
公開ファイルの構成と、更新時の確認事項を記録します。

## 問題ID

問題IDは、次の規則で管理します。

```text
フィールド-パック＋ステージ-問題番号
```

例：

```text
EQ-A1-01
AT-M2-07
AS-G3-10
```

### フィールド略称

```text
EQ：プレート・地震・火山（Earthquake）
AT：大気・海洋（Atmosphere）
AS：天文（Astronomy）
HS：地球の歴史・地層（History / Strata）
EN：環境（Environment）
```

### パック略称

```text
A：Adventurer／冒険者
M：Master／師範
G：God／神
```

## 更新時の重要確認

公開前に、必ず次の2か所のバージョン情報が一致していることを確認します。

### 1. `index.html`内の`RELEASE_INFO`

```javascript
const RELEASE_INFO = {
  version: "1.4.2",
  date: "YYYY-MM-DD",
  message: "更新内容"
};
```

### 2. `version.json`

```json
{
  "version": "1.4.2",
  "date": "2026-08-04",
  "message": "師範モード（Mパック）150問を追加"
}
```

次の3項目を、必ず一致させます。

- `version`
- `date`
- `message`

一致していない場合、最新版確認や更新履歴の表示が正しく動かない可能性があります。

---

## GitHubへアップロードする前の確認

- 必要なファイルがすべて同じ階層にある
- `index.html`が各問題ファイルを正しく読み込んでいる
- `index.html`内の`RELEASE_INFO`と`version.json`が一致している
- `logo.png`が表示される
- ローカルWebサーバーでゲームが起動する
- 問題・選択肢・解説が表示される
- ステージ進行とセーブが動作する
- GitHubへアップロード後、公開サイトでも動作確認する
